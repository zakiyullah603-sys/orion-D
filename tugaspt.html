1. apa itu version control?

Version control adalah sistem yang digunakan untuk mencatat dan mengelola perubahan pada file dari waktu ke waktu.

2. apa perbedaan gir dan github?

Git adalah software version control yang berjalan di komputer lokal untuk mengelola perubahan kode. GitHub adalah platform online untuk menyimpan repository Git dan berkolaborasi dengan orang lain.

apa itu html?

HTML (HyperText Markup Language) adalah bahasa yang digunakan untuk membuat dan menyusun struktur halaman web.
